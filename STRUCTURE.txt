Data Flow
=========

1. User clicks "Refresh Data" button
   └─> RefreshButton.jsx

2. Frontend sends POST to /api/refresh
   └─> App.js (handleRefresh)

3. Backend fetches from CBBD API
   └─> fetch_data.py (CBBDataFetcher)

4. Backend calculates ratings
   └─> calculate_ratings.py (RatingCalculator)

5. Backend saves to Supabase
   └─> app.py (Supabase client)

6. Frontend fetches updated teams
   └─> App.js (GET /api/teams)

7. Table displays teams
   └─> TeamTable.jsx

8. User clicks team row
   └─> TeamDetail.jsx expands


API Endpoints
=============

GET  /api/health            - Health check
GET  /api/teams             - Get all teams (supports ?sort_by=)
GET  /api/teams/<name>      - Get specific team
POST /api/refresh           - Fetch & update all team data
GET  /api/stats             - Database statistics

Database Schema
===============

Table: team_ratings
- id (serial primary key)
- team_name, season, conference
- overall_rating, offensive_rating, defensive_rating
- off_efg, off_orb, off_tov, off_ftr
- def_efg, def_orb, def_tov, def_ftr
- tempo
- primary_color, secondary_color, logo_url
- last_updated

Indexes:
- overall_rating (DESC)
- team_name, season (composite)


Environment Variables
====================

Backend (.env in root):
- CBBD_API_KEY          - Your CBBD API key
- SUPABASE_URL          - Supabase project URL
- SUPABASE_ANON_KEY     - Supabase anonymous key

Frontend (frontend/.env):
- REACT_APP_API_URL     - Backend API URL (http://localhost:5000)


Development Commands
===================

Backend:
cd api
python -m venv venv
venv\Scripts\activate              # Windows
source venv/bin/activate           # Mac/Linux
pip install -r requirements.txt
python app.py

Frontend:
cd frontend
npm install
npm start

Production Build:
cd frontend
npm run build
